# 2026-11-02 贡献控件与留言渲染 / Reading UI review

- 贡献图的动画开关与桌面日期输入框收紧至 36px 高；日期字体调为 14px。触屏开关保留 40px 外观及 44px 点击范围，日期输入保留 44px 高和 16px 字体。图表尺寸、贡献数据来源和更新策略保持原样。

- 不修改真实留言、账号、数据库和未提交副本；未添加针对某条留言的格式提示或改写规则。

## English

The contribution controls are more compact without shrinking the graph or mobile touch targets. Reading-feed avatars scale subtly on hover and keyboard focus, with reduced-motion support. Comments and previews now render highlight markup and standalone double-dollar formulas; code-copy controls follow the page language. Existing Markdown safety rules and stored comments are unchanged.

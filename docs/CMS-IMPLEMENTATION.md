# 站长内容后台

采用现有站长账号、Supabase 私有草稿和图片库。发布桥只生成受控内容文件，经原子 Git 提交触发现有 Pages 工作流；不提供程序、权限或密钥编辑功能。

## 内容与操作

- 文章：中英文、固定网址、日期、摘要、分类、标签、封面、评论开关，Markdown 工具栏与实时预览。
- 友链：名称、简介、地址、头像、RSS，前台仍按名称字典序排列。
- 个人资料：首页介绍、教育、关于页照片与文字、研究兴趣及联系方式。
- 学术：背景、兴趣、论文、项目；项目同时用于项目页。
- 图片：上传时转为 WebP、限制尺寸、移除元数据；私有预览、插入、修改说明、回收站与恢复。
- 内容支持保存、复制、发布、撤回、移入回收站、恢复、历史版本恢复、JSON 备份导入导出。导入和恢复先成为草稿。

## 发布边界

每次发布冻结一个文档版本。其余草稿不参与本次发布。保存使用版本号检查；同一时间只有一个发布任务。失败可重试同一任务，避免重复提交；发现仓库中的人工改动时停止覆盖。

草稿、历史和媒体桶不向匿名或普通用户开放。所有数据库入口验证当前服务端会话及站长名单；前端隐藏按钮不构成权限校验。发布凭据仅放在 Edge secrets，范围限 Cyril-Fan.github.io 的内容读写。

“已提交”与“已上线”分开。GitHub Pages 构建成功且正式站版本标记匹配后才显示上线。撤回会下架网页；已经公开的内容仍可能留在 Git 历史和第三方缓存。

## 验证范围

数据库权限、会话撤销、版本冲突、发布快照隔离、任务重试、删除/恢复；发布文件白名单、URL/Markdown/图片校验、Git 冲突；桌面和移动端编辑、预览、登录、错误恢复，以及现有站点回归。

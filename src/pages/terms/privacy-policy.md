本站的页面由 GitHub Pages 托管，没有独立访客追踪。留言服务启用时，由 Supabase 管理账户与评论数据库，Resend 发送注册验证和找回密码等账户邮件；若留言区显示“正在准备中”，当前页面尚未连接留言服务。

阅读公开留言无需注册。注册时，邮箱和密码通过加密连接交给 Supabase 认证服务；密码不保存在评论表中。邮箱用于验证、登录、找回密码和必要的账户联系，不随留言公开。只有已登录且具有有效管理权限的站长可以在留言管理菜单中按需查看作者当前账户邮箱，用于留言管理及必要联系；普通访客和其他注册用户无法读取。邮箱不另存入评论正文、公开列表或头像地址。Resend 会处理收件地址和账户邮件，不用来发送营销邮件。站长也可通过服务后台管理账户，公开访客只能看到昵称、留言、回复关系、发布时间和站长／审核标记。请勿在留言中填写密码或其他不希望公开的信息。

公开昵称属于账户资料。保存新昵称后，你的历史留言和回复引用会按最新昵称展示；已打开的其他页面刷新后可见更新。昵称不要求全站唯一，站长身份以系统授予的“站长”标记为准。站长账户固定显示为 Cyril Fan。

你可以选择上传公开头像，未设置时显示昵称首字。本站上传界面会先在浏览器中裁剪、压缩图片并去除原文件的附带信息，确认保存后才上传到 Supabase 的头像存储。头像是公开图片，持有图片地址的人可以查看；请只上传愿意公开的图片。更换或移除头像会同步影响历史留言，其他已打开的页面刷新后可见，缓存和备份可能稍后才更新。站长评论沿用本站主页头像。头像与邮箱登录相互独立，不查询邮箱服务商或 Gravatar，也不把邮箱、邮箱哈希或账户 ID 用作公开头像地址。

登录会话通常保存在当前浏览器本地存储中，用于保持登录；共享设备使用后请退出。存储不可用时，登录仅保留到页面关闭或刷新。尚未提交的留言草稿只保留在当前页面内存中，刷新或离开页面可能丢失。确认退出或切换账号时会清除旧账号的草稿；单纯的网络故障不会清除草稿。

留言支持 Markdown 排版。脚本、原始 HTML 和嵌入页面不会作为可执行内容运行；外部图片先显示来源，点击加载后才向该图片网站发送请求，且不附带当前页面地址。图片服务商仍会收到完成请求所需的 IP 地址等网络信息。

你可删除自己发布的留言：正文会清空并显示“此评论已删除”，回复关系、昵称、时间和其他人的回复会保留。站长可清理违规讨论及其回复，或限制账号发言。私有的防重复指纹、操作元数据以及服务商日志／备份可能仍按其维护周期保留；删除正文不表示所有历史副本立即消失。申请删除账户或处理其他个人信息问题，可通过下方邮箱联系站长，并完成必要的身份核实。

明暗主题选择会保存在当前浏览器的本地存储中，供下次访问使用。站内搜索在浏览器中查询静态搜索索引，本站没有接收搜索词的后台服务。
